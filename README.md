# kpoovakan  
this webpage acts like a "landing" for all coding projects developed by kpoovakan. view this webpage at [kpoovakan.github.io](https://kpoovakan.github.io).  

### keyboard navigation
a unique feature of this webpage: it is fully navigatable with a keyboard! the up and down arrow keys scroll through the webpage (scroll up and scroll down). the left and right arrow keys navigate through "cards" at each webpage section. the enter key can be used to make a selection and open the highlighted "card". for left-handed gamers, this webpage also supports WASD.
